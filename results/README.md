# Results Directory

This directory contains generated outputs and analysis artifacts produced by the Codex Alpha Computational Framework.

The current results package belongs to the v0.1.0 closed-beta research demonstrator and is based on a local Gaia DR3 demo dataset of approximately 1000 sources.

The files in this directory may include:

- anomaly detection outputs;
- feature contribution tables;
- anomaly clustering outputs;
- graph node and edge files;
- graph centrality files;
- crossmatch result files;
- exploratory visualizations;
- generated pipeline reports;
- dashboard-ready intermediate products.

These outputs support candidate-level analysis, dashboard visualization, validation planning and reproducible review.

---

## Scientific Scope

The results in this directory must be interpreted as candidate-level computational outputs.

They do **not** confirm:

- planets;
- binary systems;
- hidden companions;
- black holes;
- exotic objects;
- physical orbits;
- close encounters;
- future stellar configurations;
- observational stellar images;
- direct astrophysical discoveries.

The purpose of these results is to help identify sources that may deserve further inspection through external astronomical validation services and expert review.

## gaia_dr3_anomaly_clusters.csv

Anomaly clustering output generated from the candidate-level anomaly analysis.

This file may contain:

- cluster assignments;

Cluster membership does not confirm physical association, common origin, binarity, companionship or astrophysical class.

This file may contain:

- Gaia DR3 source identifiers;
- Gaia-derived parameters;
- anomaly scores;
- anomaly labels;
- anomaly rankings;
- candidate-level prioritization indicators.

Anomaly scores indicate statistical rarity relative to the analyzed demo population.

Important:

```text
An anomalous source does not automatically imply new physics, exotic phenomena or confirmed astrophysical discovery.
```

It indicates that the source may deserve additional inspection.

## gaia_dr3_feature_contributions.csv

This file may identify:

- which feature contributed most strongly to a candidate anomaly;

- statistical deviation indicators;
- feature-level interpretability notes.

Possible contributing parameters may include:

- parallax;
- proper motion;
- radial velocity where available;
- photometric magnitude;
- colour indicators.

This file represents an interpretability layer for anomaly ranking.

It explains internal ranking behaviour; it does not validate astrophysical classifications.

## Current Exploratory Pipeline

The current closed-beta pipeline performs the following sequence:

```text
Local Gaia DR3 demo dataset
    -> VOTable parsing
    -> multidimensional feature extraction
    -> unsupervised anomaly detection
    -> anomaly ranking
    -> feature contribution analysis
    -> candidate clustering
    -> graph construction
    -> graph centrality analysis
    -> visualization generation
    -> structured output export
    -> dashboard data preparation
```
