# Codex Alpha Computational Framework Dashboard

Local interactive dashboard for the Codex Alpha Computational Framework.

This dashboard is designed to visualize and explore the outputs generated by the local Python pipeline.

It does not require external APIs.

The dashboard reads local JSON and Markdown files generated by the command:

    python -m pipeline.run_full_pipeline

Data source:

    dashboard/public/data/

---

# Current Capabilities

The first dashboard prototype is designed to display:

- pipeline summary
- anomaly statistics
- graph node counts
- graph edge counts
- local report viewer
- future interactive 3D graph visualization

---

# Local Usage

Install dependencies:

    npm install

Run the local dashboard:

    npm run dev

The dashboard will be available locally through the Vite development server.

Typical local address:

    http://localhost:5173

---

# Design Philosophy

The dashboard is:

- local-first
- offline-ready
- open source
- API-free by default
- designed for exploratory cosmological analysis

The interface is part of the Codex Alpha Computational Framework and is intended to provide an interactive scientific visualization layer for high-dimensional astrophysical datasets.

---

# Relationship with the Python Pipeline

The dashboard does not process the raw Gaia DR3 dataset directly.

The Python framework performs the scientific pipeline and exports a local dashboard data package.

Workflow:

    Python pipeline
        -> results/
        -> dashboard/public/data/
        -> local dashboard visualization

This separation keeps the scientific computation layer and the visual interface layer modular, reproducible and independent.
