# Codex Alpha Computational Framework Dashboard

Local interactive dashboard for the Codex Alpha Computational Framework.

This dashboard visualizes and explores the outputs generated by the local Python pipeline for Gaia DR3 candidate-level analysis, anomaly ranking, astrometric dynamics, projected proper-motion evolution, stellar reconstruction and validation-oriented candidate investigation.

The dashboard is local-first and does not require external APIs for the core workflow.

It reads local JSON and Markdown files generated by:

```bash
python -m pipeline.run_full_pipeline
```

Data source:

```text
dashboard/public/data/
```

## Current Capabilities

The current dashboard provides five connected analysis interfaces:

1. **Operational Dashboard**
   - pipeline summary
   - anomaly statistics
   - graph node and edge counts
   - interactive 3D relational graph viewer
   - top structural source ranking
   - selected source inspection
   - interactive source table
   - local report viewer

2. **Advanced Analysis Layer**
   - Gaia physical map
   - relational knowledge graph
   - coherence-gradient-inspired internal proxy context
   - candidate registry
   - optional crossmatch result integration

3. **Astrometric Dynamics Lab**
   - 3D stellar field visualization
   - hybrid Gaia / dynamics view
   - kinematic velocity-space view
   - distance estimates
   - total proper motion
   - tangential velocity
   - approximate space velocity
   - dynamics index
   - hidden companion suspicion index
   - possible binary / comoving-pair candidate indicators
   - synchronized candidate selection

4. **Candidate Investigation Cockpit**
   - Candidate Signal Map 3D
   - projected proper-motion evolution of approximately 1000 Gaia DR3 demo sources
   - local tangent-plane source projection
   - individual source motion based on proper motion
   - radial-velocity contribution when available
   - projected motion traces
   - adjustable time speed
   - adjustable motion scale
   - adjustable trace intensity and trace width
   - selected-source trajectory highlighting
   - top-anomaly trajectory highlighting
   - active candidate profile
   - evidence vector
   - validation queries
   - Gaia Archive / SIMBAD / VizieR / ESA Sky links

5. **Stellar Reconstruction & Full Dossier Studio**
   - selected source summary
   - proxy-based stellar model
   - synthetic 3D stellar twin visualization
   - estimated temperature proxy
   - radius and luminosity proxies
   - procedural stellar rendering
   - Top-50 anomaly queue
   - full stellar dossier generation
   - copy-ready scientific interpretation
   - downloadable TXT / Markdown / LaTeX / JSON reports
   - synchronized source selection

## Design Philosophy

The dashboard is:

- local-first;
- offline-ready for the core workflow;
- open source;
- API-free by default;
- candidate-level;
- validation-oriented;
- designed for exploratory astronomical data analysis;
- designed to preserve separation between computation, visualization and external validation.

The interface is part of the Codex Alpha Computational Framework and provides an interactive scientific visualization layer for high-dimensional Gaia-derived astronomical datasets.

The dashboard does not replace expert astrophysical validation or official astronomical catalogue services.

---

## Relationship with the Python Pipeline

The dashboard does not process the raw Gaia DR3 dataset directly.

The Python framework performs the scientific pipeline and exports a local dashboard data package.

Workflow:

```text
Python pipeline
    -> results/
    -> dashboard/public/data/
    -> local dashboard visualization
```

This separation keeps the scientific computation layer and the visual interface layer modular, reproducible and independent.

## Scientific Boundaries

The dashboard uses explicit candidate-level language.

It does **not** confirm:

- planets;
- binary systems;
- hidden companions;
- black holes;
- exotic objects;
- close encounters;
- physical orbits;
- future stellar configurations;
- direct physical measurements;
- observational stellar images.

Projected motion traces are **not orbital simulations** and are **not N-body gravitational integrations**.

Synthetic stellar twins are **proxy-based procedural visualizations**, not observational images.

All candidate interpretations require independent validation through external astronomical services and expert review.

---

## External Validation

The dashboard supports validation planning through links and query preparation for:

- Gaia Archive;
- Gaia NSS where applicable;
- SIMBAD;
- VizieR;
- ESA Sky;
- candidate-level dossier exports.

The dashboard prepares and prioritizes candidate sources.

External astronomical services validate and contextualize them.

No official integration, endorsement or partnership with external astronomical infrastructures is claimed by this dashboard.
